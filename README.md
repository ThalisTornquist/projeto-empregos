# Projeto Empregos

Site desenvolvido com HTML5 e CSS3 para praticar desenvolvimento web e criação de interfaces com múltiplas páginas.

## Demonstração

🔗 **[Acessar o site pelo GitHub Pages](https://thalistornquist.github.io/projeto-empregos/)**

## Sobre o projeto

O projeto consiste em um site relacionado à divulgação de oportunidades de emprego, desenvolvido como parte do meu aprendizado em desenvolvimento web.

Durante o desenvolvimento, foram praticados conceitos de estruturação de páginas, navegação entre diferentes páginas, organização de conteúdo e estilização com CSS.

## Tecnologias utilizadas

* HTML5
* CSS3

## Conceitos praticados

* Estruturação de páginas com HTML
* Organização de conteúdo
* Criação de múltiplas páginas
* Navegação entre páginas
* Links internos
* Estilização com CSS
* Layout e posicionamento de elementos
* Organização de arquivos

## Estrutura do projeto

```text
projeto-empregos/
├── index.html
├── outras-paginas.html
├── css/
│   └── style.css
└── imagens/
```

*A estrutura acima pode ser ajustada de acordo com os arquivos reais do projeto.*

## Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/ThalisTornquist/projeto-empregos
```

2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

O projeto não possui dependências externas ou necessidade de instalação.

## Objetivo

Projeto desenvolvido para aprimorar conhecimentos em HTML e CSS e praticar a construção de sites organizados, com múltiplas páginas e navegação entre diferentes conteúdos.
